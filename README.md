# NER-LOGIX AI Demo v2

## Added features
- Multiple What-If disaster scenarios: heavy rainfall, landslide, flood, bridge failure, severe congestion.
- Priority shipment / emergency cargo dashboard.
- Live vehicle tracking table.
- Route intelligence comparison.
- District supply-health / supply-gap visualization.
- Weekly incident analytics.
- Automated disruption alert simulation.
- Field incident reporting.
- Presentation-mode workflow.
- Export Demo Report button.
- Responsive layout.

## Run
Extract the ZIP and open `index.html` in Chrome or Edge.

## Suggested presentation flow
1. Start on Operations Dashboard.
2. Explain the normal Guwahati → Imphal route.
3. Select Heavy Rainfall and click Run What-If Scenario.
4. Show the risk score, accessibility drop, affected network, alert and alternate route.
5. Open Priority Shipments to show medicines/food being prioritized.
6. Open Analytics & Supply to show the wider network picture.
7. Click Export Demo Report.

All operational/vehicle/incident/shipment values are simulated prototype data.
